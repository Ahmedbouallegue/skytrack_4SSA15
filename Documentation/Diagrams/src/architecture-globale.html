Architecture globale

Tout le trafic externe entre par l’API Gateway. Chaque microservice possède sa propre base de données ; aucune base n’est partagée. Les appels entre services sont détaillés page 02.

02 · Communication

Communication inter-services

Les services n’échangent que des identifiants logiques. La flèche va du service qui appelle vers le service appelé, jamais l’inverse.

Synchrone, via OpenFeign

Chaque appel a besoin de la réponse immédiatement. Le service appelé est trouvé par son nom dans Eureka (ex. location-service), jamais par une adresse en dur. Le User Service en .NET est appelé en REST/JSON comme les autres.

Seulement des identifiants

cityId et userId sont des références logiques, pas des clés étrangères : aucun service ne lit la base d’un autre. Un Long en Java correspond à un long en C#.

Si un service tombe

Timeout + circuit breaker (Resilience4j) : réponse en mode dégradé au lieu d’une erreur en cascade. Exemple : une prévision reste lisible avec cityName = null si Location ne répond pas ; la création est refusée (503).

Déploiement Docker
